# Code of Conduct

Be constructive, direct, and respectful in issues, pull requests, and reviews.

Focus feedback on code correctness, binary format evidence, reproducibility,
and engineering trade-offs. Harassment, discrimination, and personal attacks are
not acceptable.

Maintainers can remove abusive comments or restrict participation when needed.
To report a concern privately, email
[feedback@chromatic.hu](mailto:feedback@chromatic.hu).
