# Support

Use GitHub issues for bugs, format edge cases, feature requests, and
documentation fixes.

For general feedback, email [feedback@chromatic.hu](mailto:feedback@chromatic.hu).

When reporting an issue, include:

- QNNRev version or commit,
- Python version and host architecture (`x86_64` or `aarch64`),
- target QAIRT / QNN SDK version if compilation or native hooks are involved,
- the command run and the relevant console or JSON output.

Do not upload proprietary vendor SDK binaries or protected model weights to
public issues.
